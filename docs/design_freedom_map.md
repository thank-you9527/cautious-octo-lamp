# MONKEY CAROUSEL V0.4 — Design Freedom Map

日期：2026-11-09。目標：先建立可驗證的裝飾空間，不加入正式花紋或量產STL。
沿用[V0.3](v03_report.md)的`Design`、`Body`、座標轉換、誤差及三維稜柱碰撞方法，
不另造一套機構。V0.3原測試與產物保持不變。

**本文件的VERIFIED只指宣告場景、幾何代理及誤差界內的保守幾何證明。
不表示承力、實際螺絲、卡榫疲勞、列印品質或裝配已通過。**
V0.3的1.0499 mm不是可挪用的全域裝飾厚度。

## 場景、參數與輸出

保留R180、167×295×6門板、Ø6軸、OD10/ID8固定角柱、娃娃270×70×50、
軟墊5、綁帶額外4、半圓腳踏R25，以及V0.3全部傳動代理、定位、止擋與限扭代理。
每門0–240°，各門相位可獨立±0.25°；每個原構件表面／位置誤差上限0.2 mm。
新裝飾另假設0.2 mm有界誤差，維持1 mm幾何安全間隙。這些是驗收目標，非量測分布。

參數在[freedom_settings.json](../freedom_settings.json)。目前：世界角步距1°、
門局部角步距0.5°、世界完整格子10 mm、門面格寬≤10／高≤15 mm、厚度量化0.25 mm。
世界ROI為X/Y=[−400,400]、Z=[−80,850] mm。ROI之外沒有地圖等級；
ROI內自由空間也不是產品容量或可直接懸空安裝的表面。

## 連續掃掠：外包，不是離散聯集冒充精確掃掠

所有V0.3構件都是沿Z擠出的稜柱，只有繞Z運動，因此可把三維集合表示為
水平多邊形×Z區間；Z誤差仍要計入。這是完整三維幾何的特殊形式，不是忽略高度的俯視檢查。
屋頂、底座及高層齒輪即使在投影重疊，也可由Z區間排除，排除清單可追溯。

對各構件取0–240°含兩端的姿態，再對每個姿態膨脹：

`水平膨脹 m = Lθ·h/2 + Lphase·ε + e原件 + e裝飾 + c`

其中h、ε換算為弧度，ε=0.25°、e原件=e裝飾=0.2、c=1 mm。
世界座標的Lθ為`r·|轉速比|`；門件的Lphase相同，高層主輪／減速輪依V0.3轉速比計算。
Z只膨脹兩個表面誤差加安全距離，不憑空加入水平旋轉位移。
圓形旋轉代理改用包含所有原代理頂點的整周外接圓盤，這時可直接證明全角度包含，
不是用一個固定內接多邊形代表旋轉。

GEOS圓弧緩衝預設是內接折線，不能直接當嚴格外包。
本版將半徑乘`1/cos(π/(4q))`，q=4，另加1e−7 mm浮點防護，
使每個弦仍位於所需膨脹圓外。數值依賴有效的GEOS/OCCT幾何；未宣稱形式化區間算術證明。

因此完整連續角度、相位及誤差集合被包含在輸出的D內。
**D是有證據的保守外包，可能多占空間，並不是精確、最小的掃掠實體。**
世界10 mm格子只要與外包相交就標D；這使D視覺模型更保守。
反過來，只有整個格子都避開D/E/C才可標A，沒有只測格心。
`voxel_boxes.json`只是這些格子的無損合併，不會省略格子。

146組掃掠來源包含134個V0.3構件代理及12個未來門裝飾預算代理。
傳動齒形、定位接觸、限扭器仍不是最終製造幾何；既有代理有D外包，
缺少的實際零件另外列C/E，不能因為代理有掃掠就把實際機構當成已完整建模。

## A–E與驗證等級

| 分類 | 顏色／座標 | 本版意義與等級 |
|---|---|---|
|A 固定裝飾|綠／世界|完整格子避開D、E、C；**VERIFIED幾何**，固定方式另驗|
|B 隨動裝飾|青／各門局部|完整面格法向擠出，避開原機構及其他五門完整裝飾預算；**VERIFIED幾何**|
|C 條件設計|橙／世界或局部|工具、手部、拆卸、未完成接觸幾何；逐來源CONDITIONAL或UNVERIFIED；聚合層不升級，標UNVERIFIED|
|D 禁入|紅／世界|指定運動、相位、誤差與安全距離的保守外包；包含性VERIFIED，不是可用區|
|E 結構保留|藍／世界或局部|承力件、軸承、角柱固定端、螺絲及門板拆縫；未完成接頭為UNVERIFIED／CONDITIONAL，不是可用區|

D/E/C原始層可重疊。單一分類剖面優先E，再D，再C，最後A；
原始旗標及每個來源的驗證等級保留，不會把E接頭混進純維修區而漏掉結構保留。
B必須綁在自己的門，不能把θ=0的青色模型固定不動使用。

已知缺件預留包括：各門鉸鏈端／自由端固定件、上下臂、147.5 mm拆縫、
角柱上下固定支架、基座及屋頂工具區、齒輪箱實際接頭、定位／限扭細節。
未來實際零件若超出這些預留區，必須重新產生地圖，不能假裝未知零件必然裝得下。

## 六門法向厚度分布

原點是該門鉸鏈軸；X沿門寬，Z向上，裝飾外面為Y=−3，外法向為`(0,−1,0)`。
每一CSV列代表完整X/Z格子，允許體積為：

`[x0,x1] × [−3−max_certified_mm, −3] × [z0,z1]`

不是只測格心，也不是允許裝飾超出格子後仍沿用數值。
同門的軟墊、娃娃、腳踏、綁帶、輪轂、臂、延伸耳也要檢查；
只有原面板的預期安裝面接觸可豁免，不豁免整片門的所有零件。
綁帶保守包絡會向裝飾面突出，因此部分面格沒有正厚度保證。

計算時把所有障礙轉到該門座標；對另一門，令軸距為D、該障礙半徑為r：
相同轉速−1時時間速度界只需要D，相位界則為`D+2r`，可涵蓋兩門獨立誤差。
同一門各零件共用相位，時間與相位相對運動正好抵消，仍保留幾何誤差與安全距離。
對固定件及不同比例的傳動件，用`D·|ω門|+r·|ω障礙−ω門|`等一般界限。

在每個Z格帶對相對掃掠求聯集，再以整個X格寬求向−Y遇到的第一個障礙；
扣掉C/E保留後向下量化到0.25 mm。
CSV同時保留`modeled_geometry_limit_mm`與`reservation_limit_mm`，
不把缺螺絲的地方僅因為目前沒有實體就標安全。

目前每門340格，其中101格有正厚度保證，其餘為零或條件區。
搜尋上限為40 mm；部分格子取得18.25 mm，其他多數正厚度格子到達40 mm上限。
**CAP／`cap_limited=True`表示尚未找到物理最大值，40不是精確的無上限最大厚度。**
本版提供的是指定解析度、誤差及預算下「最大已證明厚度」，不是任意雕塑的全域最佳解。
0也不表示物理不可能，只表示此完整格子沒有取得正厚度證明，或落在待定保留區。

為保證六門同時加裝，另一門障礙還包含兩個完整40 mm裝飾預算區：
X27..153、Z22..135.5及159.5..273。每個已認證B格都位於這些預算內。
固定A也避開這些完整預算的連續掃掠，所以固定A與六門B可同時使用。
超出B預算、變更厚度上限或多個新增固定裝飾彼此的接合，仍需整體CAD重驗。

## 自動裝飾檢查介面

```bash
.venv/bin/python -m monkey_carousel.decoration_check \
  --box 10 2 10 --frame door0 --at 90 -4 50 --output result.json

.venv/bin/python -m monkey_carousel.decoration_check \
  --step candidate.step --frame door0 --at 90 -3 50 \
  --settings freedom_settings.json --output result.json
```

第二例假定STEP的安裝面為局部Y=0、零件在Y≤0；實際檔案請依自己的安裝基準指定XYZ。
`--frame fixed`的XYZ是世界座標；`door0..5`為各門局部座標。`--yaw`為安裝時繞Z角度。
其他初始傾斜請先在CAD內定向；運動仍跟隨門繞垂直軸。
`--host fixed/base`等可宣告安裝面，但只豁免實際零體積面接觸，不允許任意埋入宿主。
門的預設宿主是該門panel，不是整個門組。

Python可接受參數化CadQuery實體：

```python
import cadquery as cq
from monkey_carousel.decoration_check import Placement, from_shape, check
part = cq.Workplane('XY').box(10, 2, 10).translate((0, -1, 0))
p = Placement('door0', (90, -3, 50))
result = check(from_shape(part, p), p)
```

STEP／Workplane的**所有實體**都保留，使用OCCT不依賴三角網格的幾何外接盒。
凹槽與孔會被填滿，所以可能保守拒絕；從拒絕不能宣稱原STEP一定碰撞。
輸入應包含所有新增支架、螺絲及卡扣；沒提供的固定方式與強度不在驗證範圍。

檢查至少每1°全行程，保守界無法通過且沒有名義互穿時加密至0.1°。
輸出包含連續最小間隙**下界**、限制構件、限制樣本命令角／區間、
該姿態外接稜柱的精確距離，以及C/E命中。不是宣稱找到真實連續最小距離。

| 結果欄位 | 意義 |
|---|---|
|`CERTIFIED_CLEAR`|保守連續間隙下界達到要求；若命中C/E，等級仍為CONDITIONAL|
|`ENVELOPE_INTERFERENCE`|名義包絡互穿；對任意STEP不等於精確原形必定互穿|
|`INCONCLUSIVE_BOUND`|保守界不足，沒有因此虛構一個實際碰撞|
|`VERIFIED`|指定已提供幾何與預算下通過，不含未提供固定件或製造強度|
|`CONDITIONAL`|幾何可通過，但落在維修、接頭或其他待定區|
|`UNVERIFIED`|未取得幾何保證、包絡干涉或超出ROI|

介面也檢查其他門完整裝飾預算，不能只與裸V0.3模型比較。
任意超出A/B的新增件，或改變關節／維修程序，都要重新建立聯合場景。
超出B預算的單件查詢即使取得VERIFIED，也只代表回傳scope內已提供場景與其他門預算，
不延伸原A/B聯合保證；不能保留所有舊A裝飾後，僅靠單件查詢加入超界件。

## 重現、測試與限制

```bash
python -m venv --system-site-packages .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m monkey_carousel.freedom_study
.venv/bin/python -m monkey_carousel.freedom_covers
.venv/bin/python -m pytest -q
```

原V0.3產物已提交；需要重建舊版本可先跑README的原研究命令。
必須等兩個V0.4產生器完成再測試；產物寫入`outputs/v04/`。
第二個命令也完成GLB透明材質與最終PNG/SVG圖表，第一個命令的簡略PNG只是中間預覽。
來源SHA-256與完整設定均記錄，測試拒絕過期地圖。
本次51項測試通過；完整執行記錄及未驗證範圍見[V0.4驗證紀錄](v04_validation.md)。

新增測試包含採樣中間姿態、獨立相位、外接緩衝、多實體STEP、防止宿主豁免濫用、
全格A安全、D覆蓋、長方體無損壓縮、B預算、三種等級分離、
罩體／基座完整拆卸廊道與卡榫全平移／變形外包。未產生量產STL。

這是保守設計自由度圖，不是製造圖。尚須實測的V0.3材料、軸與軸承、齒形列印誤差、
定位手感、限扭校準及承載項目仍有效。地圖也沒有證明人手一定可達、
工具能按順序取出、卡榫能變形而不損壞，或所有未知零件都能塞進預留區。
新增裝飾重量若使撓度、扭轉或相位超過宣告界限，地圖即失效；40 mm空間不等於允許
填滿40 mm厚實心PETG。罩體帶與A/B也是可用空間，不是已設計完成的連續外殼或承力件。
這些項目保持CONDITIONAL／UNVERIFIED，不能被綠色或青色區域覆蓋掉。
