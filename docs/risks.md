# 設計風險與製造前關卡

V0.3最新驗證範圍、失效比較及實體關卡以 [V0.3報告](v03_report.md) 為準。
以下保留第一階段風險追蹤，並非宣稱舊R140/L90符合新外牆要求。

以下均未藉由動畫或模型匯出視為解決。

| 風險 | 目前處置 | 正式零件前必須完成 |
|---|---|---|
| 六門相位誤差／背隙／跳齒 | 僅驗證理想同步，不涵蓋失同步 | 在所有門獨立相位誤差、張力與負載範圍重新掃描 |
| 單門卡住造成夾傷或娃娃受力 | 尚無過載保護 | 扭矩限制、可逆操作、手指防護、240°雙向止擋與慢速解鎖測試 |
| 綁帶鬆脫或娃娃姿態變化 | 270×70×50 mm 包絡；綁帶額外 4 mm 假設 | 用實際娃娃、頭髮、衣裝、手臂與鬆帶實測包絡 |
| PETG 潛變／層間剝離／溫度與濕度 | 未套用無來源材料許用值 | 指定料號、列印方向與實測試片；長期懸臂負重及溫度測試 |
| Ø6 軸撓度、扭轉、過懸與接頭鬆動 | 僅標準尺寸與條件式計算 | 確定鋼材、公差、門重與重心；計算撓度、固定方式、軸向推力與壽命 |
| 軸承／座孔／軸配合 | 606-2RS 6×17×6 mm 候選，24×24×6 座包絡 | 查供應商圖面及負載；PETG 校正試片，避免把收縮座孔當成可靠壓配 |
| 傳動接觸 | 刻意排除皮帶／對應皮帶輪及同門軸接觸 | 牙型、齒數、節距、張力器、包角、偏移與耐久完整 CAD/負載驗證 |
| 屋頂中央旋鈕 | q=3 兩層齒帶概念 | 中央支承、輸入軸、旋鈕連接與拆卸程序；傳動蓋板、防夾與手部淨空 |
| 傳動空間代理過度保守或遺漏 | 已加入輪、帶、屋頂、606 座包絡 | 張力器、緊固件、軸環、實際輪轂及拆件接縫建模後再檢查 |
| 尺寸搜尋非全域最佳 | 粗格點及R137–139/L88–90局部1 mm細搜尋 | 門寬／外觀／載荷選定後細化，且把傳動與製造限制放入搜尋 |
| 2 mm 間隙預算不足 | 是設計假設，沒有量產統計依據 | 列印／裝配校正與相位誤差疊加，不以任意成功百分比替代 |
| 大零件超出印床／接縫柔弱 | 已規劃拆件，未設計製造 CAD | 選定印床、每件包圍盒、接合剛性、緊固及重複定位後重新掃描 |
| 傾倒與底座剛性 | 未知總重量及外力 | 最不利六娃娃姿態重心、底座支撐多邊形、傾覆／側推試驗 |

製造前關卡：完整驅動與接頭幾何 → 公差及相位掃描 → 有來源載荷／材料計算
→ 校正與小型治具試驗 → 設計審查 → 才產生正式列印 STL。
